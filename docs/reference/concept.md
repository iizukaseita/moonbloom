# Moonbloom — コンセプトシート

## 一言で

**「夜、よるまるに今日の気分を伝えると、夜空の庭に花が咲く。」**

気分を記録するだけで終わらない。マスコットが寄り添い、小さなアクションを提案し、毎日の記録が花として積み重なる — 癒しの気分トラッカー。

## コアストーリー

よるまるが住む「夜空の庭」。

毎晩、よるまるが「今日はどんな日だった？」と聞いてくれる。気分をタップすると、よるまるがひとこと寄り添い、小さなアクションを提案してくれる。そして庭に花の種が蒔かれ、毎日の記録を続けると、つぼみが育ち、やがて花が咲く。

**設計思想：気分が悪い日も、記録すること自体が「水やり」。**

良い日も悪い日も、自分と向き合った時間が花を育てる。気分の良し悪しで花の成長は変わらない。記録を続けること自体に価値がある、という思想。

---

## マスコット

### よるまる

- 夜空に浮かぶ、丸い月のキャラクター
- 1日の終わりにユーザーに寄り添う存在
- 柔らかく、温かみのある性格
- 語尾は「〜まる」（日本語版）
- 英語版では語尾なし、優しいトーンで統一
- 気分に応じて表情が変わる（にっこり、心配顔、うるうるなど）

### 庭の花（つぼみん的要素）

- 独立したキャラクターではなく、「仕組み」として組み込む
- 記録の積み重ねで花が育つビジュアルフィードバック
- たまごっち的な「毎日開きたくなる」力を生む

## UXフロー（v1）

```
① 通知（夜、ユーザーが設定した時間に1回だけ）
   よるまる「今日はどんな日だった〜まる？」

② 気分選択（1タップ、5段階）
   😄 最高 / 😊 いい / 😐 ふつう / 😔 もやもや / 😢 つらい

③ よるまるのリアクション + ひとこと提案（軽め）
   😄 → 「きらきらの日だったまる〜✨ 何が良かったか心にしまっておくまる！」
   😊 → 「いい日だったまる〜😊 その調子まる！」
   😐 → 「おつかれさままる〜。ゆっくり休むまる🌙」
   😔 → 「そんな日もあるまる。あったかい飲み物でも飲むまる〜🍵」
   😢 → 「よしよしまる…。深呼吸してみるまる。ゆっくりでいいまる🌿」

④ 庭に変化
   花のつぼみが少し成長するアニメーション（短く、心地よく）

⑤ 完了。アプリを閉じる。
   所要時間：5〜10秒
```

**やらないこと（v1）：**
- 活動記録（何をしたか）
- 写真・音声メモ
- 習慣トラッカー
- 目標設定
- SNS共有
- 複雑な統計・分析

---

## 庭の育成ロジック

- 1回記録 = 1日分の成長（気分の良し悪しは関係なし）
- 7日連続記録 → 最初のつぼみが咲く
- 30日連続 → 新しい種類の花が解放
- 記録を忘れた日があっても花は枯れない（罰を与えない設計）
- 月ごとに季節の花が変わる（1月＝冬の花、4月＝桜など）

**育成は気分の内容に依存しない。** 泣いた日も笑った日も、同じだけ花は育つ。「記録する行為」そのものを肯定する設計。

## 多言語対応方針

- v1: 日本語 + 英語
- UIテキストが極めて少ないため、ローカライズコストは低い
- よるまるの語尾は言語ごとにローカライズ
  - 日本語：「〜まる」
  - 英語：語尾なし、柔らかいトーン（"What a lovely day!" / "It's okay. Take it easy tonight.")
- アプリ名「Moonbloom」は全言語共通
- App Storeの説明文・スクリーンショットは言語別に用意
